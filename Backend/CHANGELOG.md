# تاریخچه تغییرات

همه تغییرات قابل توجه در این پروژه در این فایل ثبت خواهد شد.

## [1.0.0] - 2024-07-18

### اضافه شده
- ساختار پایه پروژه FastAPI
- ماژول مدیریت جلسات کاربران
- ماژول مدیریت املاک با API خارجی
- سیستم زمانبندی برای به‌روزرسانی خودکار داده‌ها
- مدل‌های SQLAlchemy برای ذخیره‌سازی داده‌ها
- مستندسازی API با Swagger UI

### بهینه‌سازی‌ها
- بهبود مدیریت چرخه حیات برنامه با استفاده از lifespan
- بهینه‌سازی اتصال به دیتابیس با تنظیمات پیشرفته
- پیکربندی پیشرفته لاگینگ
- مدیریت بهتر متغیرهای محیطی
- استفاده از Alembic برای مدیریت مهاجرت‌های دیتابیس

### اصلاح شده
- رفع مشکل خطای Swagger UI با تنظیم نسخه OpenAPI
- بهبود سیستم مدیریت خطاها
